An AI-written processor can pass a benchmark without proving that it is ready to manufacture. OpenAI's November 2026 report evaluated two tasks: improving existing RISC-V RTL and designing a core from written requirements. Both paths used simulation checks, an area cutoff, hidden workloads, and a Yosys clock estimate to produce a relative throughput score.

Those checks establish something useful but specific: a design passed the reported tests and scored well under that evaluation's rules. Simulation covers the cases that ran. The clock figure is an estimate, and the score is normalized to the best result within each core's setup. A specification can also omit features that the existing core already supports.

The report separately says model-proposed Jalapeño block changes reduced standard-cell area and were proven during silicon bring-up. That evidence applies to those blocks; it is not proof that the benchmarked RISC-V designs became chips.
