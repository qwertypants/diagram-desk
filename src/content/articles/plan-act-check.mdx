An agent becomes dependable when its next step depends on observed results and every loop has a clear end.

## The problem

Open-ended work cannot be safely expressed as an endless sequence of model calls.

## Read the architecture

Locate the feedback edge from tools to assessment, then follow each terminal path.

### Walk through it

#### 1. Clarify and plan

A human request becomes a clarified task and an initial plan.

#### 2. Act and inspect

Tools affect the environment. Tool results and code execution provide observations for assessing progress.

#### 3. Continue or stop

Continue by replanning; pause at a checkpoint; stop on completion or a reached limit. Human feedback can restart planning.

## Design decisions

- Assess actual tool results rather than treating a plan as progress.
- Make maximum iterations or cost an explicit stopping rule.

## Failure modes

- A successful tool call may still fail the user objective.
- A checkpoint without a resume condition leaves ambiguous state.

## Key takeaways

- A credible completion claim requires external evidence.
