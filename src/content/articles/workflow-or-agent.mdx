Start with the smallest approach that meets the task. Add model-directed control only when measured outcomes justify it.

## The problem

A flexible agent can be expensive and unpredictable when a fixed workflow would suffice.

## Read the architecture

Follow the decision from one call through predictable workflows to agent-directed work and back to evaluation.

### Walk through it

#### 1. Try one call

Check whether retrieval and examples make a single model call sufficient.

#### 2. Choose control

Use code-directed workflows for predictable steps; consider an agent when the process itself must be discovered.

#### 3. Measure

Evaluate outcomes. If added complexity does not improve them, return to the simpler design.

## Design decisions

- Workflows favor predictability; agents trade some control for flexibility.

## Failure modes

- A sophisticated demonstration may fail repeated task evaluation.

## Key takeaways

- Complexity is a cost to justify with outcomes.
